# Project 01: Netflix Exploratory Data Analysis (EDA)

## Objective

Analyze the Netflix Movies and TV Shows dataset to discover patterns, trends, and business insights through data cleaning, exploration, and visualization.

## Dataset

Netflix Movies & TV Shows Dataset:
https://www.kaggle.com/datasets/shivamb/netflix-shows

## Tasks Performed

### Data Inspection
- Loaded dataset using Pandas
- Checked shape and data types
- Identified missing values
- Checked duplicate records

### Data Cleaning
- Handled missing values
- Removed duplicates
- Fixed inconsistent data types
- Cleaned relevant columns

### Exploratory Data Analysis
- Content distribution by type
- Top producing countries
- Most common ratings
- Release year trends
- Genre analysis

### Visualizations
- Bar Chart
- Line Chart
- Histogram
- Scatter Plot
- Pie Chart
- Heatmap

## Key Insights

- Movies dominate Netflix content.
- Content production increased significantly after 2015.
- A few countries contribute the majority of titles.
- TV-MA is among the most common ratings.
- Certain genres are consistently more popular.

# Project 02: Iris Flower Classification

## Objective

Build and compare multiple Machine Learning models to classify Iris flower species using flower measurements.

## Dataset

Iris Flower Dataset:
https://www.kaggle.com/datasets/uciml/iris

## Features

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Target

- Iris Setosa
- Iris Versicolor
- Iris Virginica

## Preprocessing

- Checked for missing values
- Split dataset into training and testing sets (80/20)
- Feature correlation analysis
- Prepared data for model training

## Models Used

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Random Forest Classifier

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Results

The models were compared using classification metrics. Random Forest achieved the best overall performance and provided the highest classification accuracy on the test dataset.

## Conclusion

The Iris dataset is well-structured and highly suitable for classification tasks. Multiple machine learning algorithms were trained and evaluated successfully. Random Forest performed best due to its ability to capture feature relationships effectively and generalize well on unseen data.
